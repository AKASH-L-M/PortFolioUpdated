# Akash L M — Portfolio

This is a modular rewrite of the original single-page portfolio. The visual design, animations, carousels, panels, and navigation are preserved, while the source is separated by responsibility.

## Run locally

The project uses real HTML partial files, loaded by frontend JavaScript. Open the folder using **VS Code Live Server**, or deploy it to any static host such as GitHub Pages, Netlify, or Vercel.

Do not double-click `index.html` using a `file://` URL. Browsers block JavaScript from loading local HTML partials for security reasons.
